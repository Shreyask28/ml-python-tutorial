## 🛠️ Getting Started

To use these tutorials on your local machine, follow these steps:

**1. Clone the repository:**
```bash
git clone [https://github.com/Shreyask28/ml-python-tutorial.git](https://github.com/Shreyask28/ml-python-tutorial.git)
cd ml-python-tutorial
```

**2. Create a virtual environment (Recommended):**
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

**3. Install dependencies:**
```bash
pip install -r requirements.txt
```

**4. Launch Jupyter Notebook:**
```bash
jupyter notebook
```
*(Alternatively, you can open the `.ipynb` files directly in Google Colab or VS Code).*
